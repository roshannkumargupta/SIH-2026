# SmritiSetu Internationalization (i18n) Architecture

SmritiSetu provides full-platform multilingual accessibility across **11 official Indian languages**, clinically optimized for elderly individuals and individuals living with cognitive conditions (such as Alzheimer's, dementia, and MCI).

---

### Script Notes & Tofu Prevention
- **Manipuri (`mni`)**: Rendered using modern Eastern Nagari / Bengali script (`মৈতৈলোন্`, `য়ুম`, `ৱাখলগী খেল`, `হিদাক`, `নীংশিংবা`), universally readable across Android, iOS, Windows, and Linux.
- **Bodo (`brx`)**: Uses official Devanagari script (`बड़ो`, `नखर`, `गेमफोर`, `मुली`, `गोसोखांथि`).
- Google Fonts (`Noto Sans Bengali`, `Noto Sans Devanagari`, `Noto Sans Telugu`, `Noto Sans Tamil`, `Noto Sans Gujarati`) along with system fallback (`Nirmala UI`) ensure zero missing glyphs or "tofu" boxes across all viewports.

## 2. Core Architecture

SmritiSetu utilizes an integrated i18n architecture:

```
[ UI Components & Routes ]
          │
          ▼
   useLanguage()  ─────────────►  useTranslation() (react-i18next)
          │                                  │
          ▼                                  ▼
[ LanguageContext ]                  [ i18next Engine ]
   ├── LocalStorage Cache            ├── 11 Dictionaries (8 Namespaces)
   ├── Window Event Dispatch         └── Fallback to en-IN
   └── Backend Profile Persist (/auth/me)
```

### Key Files
- `Frontend/src/i18n/config.ts`: i18next initialization with browser language detector and all 11 dictionaries.
- `Frontend/src/i18n/resources/*.ts`: Strongly typed dictionaries for all 11 languages.
- `Frontend/src/context/LanguageContext.tsx`: Context bridge exposing unified `t()`, `language`, `setLanguage()`, and `supportedLanguages`.
- `Frontend/src/hooks/use-translated-text.ts`: Dynamic translation hook for user-generated content (patient notes, memory descriptions) with client-side hashing and caching.
- `Frontend/src/routes/__root.tsx`: Injects i18n configuration and Google Fonts.
- `Frontend/src/styles.css`: Defines responsive typography tokens with Indic font fallbacks.

## 3. Namespace Structure

Translations are organized into 8 modular namespaces:

| Namespace | Scope & Contents |
| :--- | :--- |
| `common` | Navigation headers, universal action buttons (`save`, `cancel`, `playNow`, `done`, `delete`), offline sync banners. |
| `dashboard` | Dynamic greetings (morning, afternoon, evening), cognitive challenge summary, medication snapshot, memories card, daily routine checklist. |
| `games` | Cognitive Training Centre, categories, session metrics, game shell headers, difficulty levels, How-to-Play instructions, results modal. |
| `medication` | Daily dose schedule, adherence progress bar, dose timeline, doctor prescriptions list, instructions. |
| `memories` | Reminiscence album, category filters, memory creation modal, voice story playback prompts. |
| `routine` | Structured daily activities, priority tags, time slots, completion toggles, new activity modal. |
| `analytics` | Cognitive progression score, AI risk evaluations, 4 cognitive domain breakdowns, clinical recommendations. |
| `auth` | Sign-in and registration forms, patient/caregiver/doctor role selectors, validation labels. |

## 4. Usage Guide for Developers

### Basic Translation in Components
Use the `useLanguage()` hook from `@/context/LanguageContext`:

```tsx
import { useLanguage } from "@/context/LanguageContext";

export function ExampleComponent() {
  const { t } = useLanguage();

  return (
    <div>
      <h1>{t("dashboard:brainChallenge")}</h1>
      <p>{t("common:save")}</p>
    </div>
  );
}
```

### Parameter Interpolation
Interpolations use the standard `{{param}}` format:

```tsx
// Resource: "Good morning, {{name}}"
t("dashboard:greetingMorning", { name: "Lalita" });

// Resource: "You completed {{sessions}} exercises with {{accuracy}}% accuracy."
t("dashboard:memoryMatchStats", { sessions: 12, accuracy: 94 });
```

### Dynamic / User-Generated Content
For user-entered descriptions or clinical notes that are not in the static dictionary:

```tsx
import { useTranslatedText } from "@/hooks/use-translated-text";

export function MemoryCard({ description }: { description: string }) {
  const { translatedText, isTranslated, isLoading } = useTranslatedText(description);

  return (
    <div>
      <p>{translatedText}</p>
      {isTranslated && (
        <span className="text-xs text-cream/50">Translated automatically</span>
      )}
    </div>
  );
}
```
`useTranslatedText` caches translations in `localStorage` keyed by `smritisetu_dynamic_trans_<lang>_<hash>`, preventing duplicate network calls.

## 5. Adding a New Language

1. **Create the Dictionary**:
   Add a new file in `Frontend/src/i18n/resources/<lang>.ts` implementing all 8 namespaces (`common`, `dashboard`, `games`, `medication`, `memories`, `routine`, `analytics`, `auth`).

2. **Register in `Frontend/src/i18n/config.ts`**:
   ```ts
   import { ml } from "./resources/ml"; // Malayalam example
   export const resources = {
     // ...
     "ml-IN": ml,
     ml,
   };
   ```

3. **Add to `SUPPORTED_LANGUAGES_LIST`** in `Frontend/src/context/LanguageContext.tsx`:
   ```ts
   { code: "ml-IN", name: "Malayalam", nativeName: "മലയാളം" },
   ```

4. **Verify Fonts**:
   Ensure the script is linked in `Frontend/src/routes/__root.tsx` and declared in `Frontend/src/styles.css`.

## 6. Voice Assistant & Backend Synchronization

When a patient changes language via the header dropdown:
1. `i18n.changeLanguage(code)` triggers instant re-render across the entire React component tree.
2. `localStorage.setItem("smritisetu_preferred_language", code)` persists preference offline.
3. Custom event `smritisetu:language-change` is broadcast to synchronize the Web Speech API voice synthesis and speech recognition engines in `useVoiceAssistant`.
4. If authenticated, `authApi.updateProfile({ preferred_language: code })` syncs the preference with PostgreSQL database.
